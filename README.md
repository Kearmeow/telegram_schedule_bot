# Telegram Schedule Bot + Mini App

Telegram-бот и Mini App для расписания учебных групп.

## Что умеет

- просмотр расписания по группе и дню;
- запоминание выбранной группы;
- админка прямо в Mini App;
- создание и удаление групп;
- добавление, редактирование и удаление занятий;
- массовый импорт расписания из Excel `.xlsx`;
- автоматическое создание групп при импорте;
- режим импорта **добавить** или **заменить расписание импортируемых групп**;
- генерация Excel-шаблона из админки;
- PostgreSQL для постоянного хранения на RelaxDev;
- SQLite как локальный fallback.

## Excel-импорт

В админке открой **📥 Excel** и скачай шаблон.

Обязательные колонки:

```text
Группа | День | Начало | Конец | Предмет
```

Дополнительные:

```text
Преподаватель | Аудитория | Заметки
```

День можно указывать как `Пн`, `Вт`, `Ср`, `Чт`, `Пт`, `Сб`, `Вс` или полностью.

Пример:

| Группа | День | Начало | Конец | Предмет | Преподаватель | Аудитория | Заметки |
|---|---|---|---|---|---|---|---|
| ИС-21 | Пн | 08:30 | 10:00 | Математика | Иванов И.И. | 301 | |
| ИС-21 | Пн | 10:10 | 11:40 | Информатика | Петров П.П. | 205 | |

## RelaxDev

Создай PostgreSQL и добавь переменные:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=твой_telegram_id
WEBAPP_URL=https://адрес-проекта.relaxdev.ru
```

`DATABASE_URL` оставь переменной, которую предоставляет RelaxDev вместе с PostgreSQL.

Команда запуска:

```bash
python -m app.main
```

## Важно

- `.env` не загружать в Git.
- `BOT_TOKEN` никому не показывать.
- Для RelaxDev используй PostgreSQL, а не SQLite.


## Быстрый ввод расписания

В админке появилась вкладка **«✍️ Быстрый ввод»**. Можно указать группу и вставить расписание обычным текстом:

```text
Понедельник
08:30-10:05 Математика | Иванов И.И. | 301
10:15-11:50 Информатика | Петров П.П. | 205

Вторник
08:30-10:05 Программирование | Сидоров | 205
```

Есть режимы **заменить расписание группы** и **добавить к существующему**.


### Если /admin пишет «нет доступа»

Отправь боту `/id`. Он покажет фактический Telegram ID и username.  
Укажи один из них в переменных RelaxDev:

```text
ADMIN_IDS=123456789
```

или

```text
ADMIN_USERNAMES=my_username
```

После изменения переменных сделай redeploy.
